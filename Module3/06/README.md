# UDP Broadcast Chat

Групповой чат на основе UDP-сокетов и широковещательной
рассылки. Все клиенты равноправны: каждый экземпляр программы
может отправлять и принимать сообщения

## Сборка

```bash
make
```

Для удаления результатов сборки:

```bash
make clean
```

## Запуск

```bash
./chat
```

Введите текст и нажмите Enter, чтобы отправить сообщение.

Для выхода введите `/quit` или нажмите `Ctrl+C`.

## Проверка

Для локального тестирования запустите программу в нескольких
терминалах. Для проверки между компьютерами они должны находиться
в сети, допускающей UDP broadcast на порт `45454`.

Если сообщения не приходят, проверьте выбранный сетевой интерфейс,
настройки брандмауэра и доступность широковещательной передачи.
