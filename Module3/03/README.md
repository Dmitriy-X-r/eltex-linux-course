
# POSIX Message Queues

## Описание

Программа реализует двусторонний асинхронный обмен сообщениями между
двумя экземплярами программы с использованием POSIX-очередей сообщений.

Для обмена используются две очереди:
- `<имя>_1` — первая очередь;
- `<имя>_2` — вторая очередь.

Первый процесс создаёт очереди, принимает сообщения из первой очереди
и отправляет сообщения во вторую. Второй процесс использует очереди
в обратном направлении.

Для завершения обмена используется специальный приоритет сообщения.
Завершить работу можно командой `/exit` или сигналом SIGINT (Ctrl+C).

Процесс, создавший очереди, удаляет их после завершения работы.

## Сборка

```bash
make
```

## Запуск

В первом терминале:

```bash
./chat mychat
```

Во втором терминале:

```bash
./chat mychat
```

Оба процесса должны использовать одинаковое имя очередей.

## Завершение

Введите `/exit` или нажмите Ctrl+C.

## Очистка

```bash
make clean
```
