# Task 10 — Taxi dispatcher

Диспетчер такси на Cи для Linux.

Программа создаёт отдельные процессы-водители с помощью `fork()`.
Обмен командами и ответами выполняется через анонимные каналы `pipe()`.
Для мультиплексирования используется `select()`, а для выполнения
задач с ограничением по времени — `timerfd`.

## Сборка

```bash
make
```

## Запуск

```bash
./taxi
```

## Команды

- `create_driver` — создать водителя.
- `send_task <pid> <task_timer>` — назначить задачу на указанное число секунд.
- `get_status <pid>` — запросить состояние водителя.
- `get_drivers` — запросить состояние всех водителей.
- `help` — показать список команд.
- `quit` — завершить диспетчер и созданные процессы.

Время задачи задаётся в секундах, от 1 до 86400.

## Очистка

```bash
make clean
```
