
# Publisher-Broker-Subscriber

Программа на C для обмена сообщениями между процессами
с использованием очереди сообщений System V и сигналов.

## Сборка

```bash
make
```

Удаление результатов сборки:

```bash
make clean
```

## Запуск

Каждый процесс запускается в отдельном терминале.

### 1. Запустить брокер

```bash
./pubsub -b
```

Брокер создаёт очередь сообщений. Одновременно может работать
только один брокер с заданным ключом очереди.

### 2. Запустить подписчика

```bash
./pubsub -s sports news
```

Подписчик получает сообщения по темам `sports` и `news`.

### 3. Запустить издателя

```bash
./pubsub -p sports
```

Вводите текст сообщений в терминале издателя. Сообщения будут
передаваться подписчикам темы `sports`.

### 4. Завершение

Нажмите Ctrl+C в терминале брокера, чтобы остановить его.
Брокер уведомляет зарегистрированных участников сигналом SIGINT
и удаляет очередь сообщений.

Подписчика или издателя можно остановить отдельно с помощью Ctrl+C.

## Принцип работы

- Команды издателей и подписчиков отправляются в очередь с `mtype = 1`.
- Брокер принимает команды с `mtype = 1`.
- Брокер отправляет сообщения с `mtype`, равным PID подписчика.
- Подписчик читает сообщения только со своим типом.
