
# Task 9 — Raw sockets, САОД и signals

UDP echo-client и echo-server на raw sockets.

Сервер самостоятельно разбирает IPv4 и UDP заголовки,
возвращает текст сообщения с порядковым номером для каждого
клиента и хранит счётчики в хеш-таблице.

Клиент использует отдельный исходный UDP-порт.
При штатном завершении отправляет серверу сообщение о закрытии.

## Сборка

```bash
make
```

## Запуск сервера

```bash
sudo ./echo_server 9000
```

Порт можно не указывать: по умолчанию используется 9000.

## Запуск клиентов

В отдельных терминалах:

```bash
sudo ./echo_client 127.0.0.1 9000 50001
```

```bash
sudo ./echo_client 127.0.0.1 9000 50002
```

Последний аргумент — исходный UDP-порт клиента.
Для одновременной работы клиенты должны использовать разные порты.

Для завершения клиента нажмите Ctrl+C или отправьте EOF.
При штатном завершении клиент уведомляет сервер.

## Очистка

```bash
make clean
```

## Примечание

Raw sockets требуют соответствующих привилегий.
В данном варианте UDP checksum отключена (значение 0),
что разрешено для IPv4 UDP.
