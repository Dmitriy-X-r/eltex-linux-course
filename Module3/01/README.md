# Task1 — Fork, files and pipes

Программа на C для изучения взаимодействия
родительского и дочернего процессов в Linux.

## Сборка

make

Запуск

Анонимные каналы (pipe)

./filecopy file1.txt file2.txt

Программа копирует каждый указанный файл в файл с суффиксом .copy.

Именованные каналы (FIFO)

./filecopy -p /tmp/filecopy.fifo file1.txt file2.txt

В этом режиме программа использует два именованных канала:

/tmp/filecopy.fifo — передача данных от родителя к ребёнку;

/tmp/filecopy.fifo.reply — передача ответов от ребёнка родителю.

Каналы создаются перед обменом и удаляются после завершения программы.

Пример

./filecopy first.txt second.txt

Результат:

first.txt.copy
second.txt.copy

Если исходный файл не удаётся открыть, программа выводит сообщение об ошибке и продолжает обработку следующих файлов.

Очистка

make clean

Команда удаляет объектные файлы и исполняемую программу.
