# Task7.1 — TCP-чат

Групповой чат на C с использованием TCP-сокетов.

## Сборка

```bash
make
```

## Запуск сервера

```bash
./chat_server
```

## Запуск клиента

На том же компьютере:

```bash
./chat
```

На другом компьютере:

```bash
./chat 192.168.1.10
```

Вместо `192.168.1.10` укажите IPv4-адрес компьютера,
на котором запущен сервер.

## Использование

- Введите текст для отправки сообщения другим участникам.
- Введите `/quit` для отключения от чата.
- Нажмите Ctrl+C для завершения работы.

Сервер использует epoll(), клиент — poll().
