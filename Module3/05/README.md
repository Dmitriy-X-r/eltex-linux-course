# Producer-Consumer with POSIX

## Описание

Программа демонстрирует межпроцессное взаимодействие
с помощью разделяемой памяти POSIX и семафора.

## Сборка

```bash
make
```

## Запуск

1. В первом терминале запустить производителя:

   ```bash
   ./producer_consumer producer
   ```

2. Во втором терминале запустить потребителя:

   ```bash
   ./producer_consumer consumer
   ```

3. При необходимости в третьем терминале запустить
   ещё одного потребителя:

   ```bash
   ./producer_consumer consumer
   ```

Производитель размещает блоки случайных чисел в сегменте
размером 512 байт. Потребители находят минимальное
и максимальное значения и помечают блоки обработанными.

Производитель завершает работу после заполнения памяти
и обработки всех созданных наборов.

## Очистка объектных файлов

```bash
make clean
```
