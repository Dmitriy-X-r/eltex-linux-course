# UDP RAW Packet Capture

Программа для захвата и анализа UDP-пакетов в Linux
с использованием RAW-сокета AF_PACKET.

## Возможности

- Фильтр сообщений UDP-чата из задания 6.
- Фильтр DNS-пакетов через UDP.

## Сборка

```bash
make
```

Запуск
Для доступа к RAW-сокету нужны соответствующие привилегии:

```bash
sudo ./capture
```

Выберите фильтр и длительность захвата в секундах.

Если выбираем первый фильтр, то в отдельном терминале нужно запустить программу из задания 6
Если выбираем второй фильтр, то в дополнительном терминале нужно запустить

```bash
getent ahostsv4 example.com
```

Для досрочного завершения нажмите Ctrl+C.
Результаты
Данные отображаются в терминале и сохраняются в capture.txt.

Очистка
```bash
make clean
```
